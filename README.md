# Chimera CLI (NEXUS-OMEGA)

“Chimera CLI” 是一个面向开发者的命令行 AI 编程智能体工具，代号 **NEXUS-OMEGA**。它采用进化型、稀疏型 Agent 架构，旨在提供可扩展的自动化开发辅助与工作流编排。

## 功能概览

- 基于 Agent 的任务调度与执行策略
- 可通过插件/模块扩展能力
- 以 Rust 为主要实现语言，注重性能与安全

## 快速开始

构建并运行（需要已安装 Rust 工具链）:

```bash
# 克隆仓库
git clone https://github.com/Yoloccyt/Chimera-CLI-.git
cd Chimera-CLI-

# 使用 cargo 构建
cargo build --release

# 运行可执行文件（示例）
./target/release/chimera-cli --help
```

## 安装

可以直接使用 cargo 安装（若已发布到 crates.io）：

```bash
cargo install chimera-cli
```
