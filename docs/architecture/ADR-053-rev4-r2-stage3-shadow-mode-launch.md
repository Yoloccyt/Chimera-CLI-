## 决策 3A′-P2:游程哨兵单侧化 + 下界兜底(定死 R3-E06-1)

**根因**:rev3 的 Wald–Wolfowitz 游程检验是**双侧**——游程过少(正自相关)触发 bootstrap
更保守(fail-closed,对);但游程**过多**(负自相关)也触发拒绝,此时 moving block
bootstrap 方差常小于二项,下界反而抬高、更易晋级(**fail-open 暗道**)。

**定死方案(两重 fail-closed,叠加)**:

1. **哨兵单侧化**:游程检验**只对"游程过少"(正自相关/聚集)单侧拒绝**(α=0.10)。
   负自相关(游程过多)**不触发 bootstrap 分支**——负自相关只会使 Wilson 更保守,无需
   切换,消除 fail-open 暗道。
2. **下界兜底(二次保险)**:即便哨兵拒绝转入 moving block bootstrap,**最终采用
   `min(Wilson 下界, bootstrap 下界)`**——保证切换到 bootstrap 永远不会比 Wilson 更宽松。

**净效果**:两分支下晋级门都 **≤ Wilson 下界**,单调 fail-closed;哨兵低功效不再是隐患
(即便漏判,兜底的 min 也不会放松)。E06 复评指出的"bootstrap 分支近乎摆设"由此转为
特性——它只在能**收紧**时才生效。

## 决策 3A″-P2:每维最低得分硬门 s_min(定死 R3-E02-1)+ N_probe 收口

**根因(R3-E02-1)**:w_min=0.20 防"权重归零",但变体可在 0.60 权重维刷高分、另两维
踩 0.20 权重的及格线仍过 ε_win——w_min 防不了"权重集中 + 他维踩线"。

**定死方案**:在 rev3 合取硬门中,对 A/B/C 三加权维**各加绝对得分硬门 s_min**(独立于
权重,任一维绝对分 < s_min 即该批直接计非胜):

| 维 | s_min | 锚点依据 |
|----|-------|---------|
| A 执行面 | **≥0.9** | 沿用 pvl `VERIFY_PASS_RATE_THRESHOLD`=0.9(已是执行硬门前提) |
| B 变异分 | **≥0.5** | 沿用 ProcessScorer `LOW_QUALITY_THRESHOLD`=0.5(低于半数变异杀伤=测试套件不合格) |
| C held-out | **≥0.5** | 未见任务至少半数胜(低于即过拟合信号,与 B 同档) |

> **s_min 取值待用户确认档位**:上表为"接地既有代码常量"的初始档;可按安全裕度调严
> (如 B/C→0.6)或调松(→0.4)。**硬门语义(绝对分 < s_min 即非胜)不变,仅数值可调**。

**踩线攻击失效原理**:加 s_min 硬门后,他维不能只踩"权重及格线"(加权贡献),而必须
各自**绝对分 ≥ s_min**——变体在 A 维刷 1.0 也无法补偿 B 维 0.3(<0.5 硬门直接非胜)。
"资格(每维 s_min 硬门 + D AHIRT + 真实执行 + 覆盖率一致)→ 排名(A/B/C 加权 ε_win)"
两层结构,资格层堵死踩线。

**N_probe 收口(顺带 R3-E01-2)**:N_probe=100 为**固定下限**;"升 300"从 rev3 标定列
**删除**(无预注册触发条件,属 rule-shopping 回潮)。若阶段③ 实跑需提高,须另立预注册
触发规则(仿 25 批扩展写法),不留自由裁量口子。

## 后果

**正面**:
- R3-E06-1 定死:单侧哨兵 + min 兜底使晋级门**单调 ≤ Wilson**,消除 fail-open 暗道,
  哨兵低功效不再是隐患
- R3-E02-1 定死:每维 s_min 硬门堵死"权重集中 + 他维踩线",踩线攻击失效
- 诚实二分:2 项可定的定死、6 项须实跑的显式登记,不把待标定伪装成已闭合(延续 rev2/rev3 诚实)
- N_probe 升 300 悬空口子删除,消除 AHIRT 门的 rule-shopping 回潮

**负面/风险**:
- s_min 具体档位仍需用户确认(rev4 给接地初始值,非终值)
- 6 项须实跑项使阶段③ 启动前工程量维持高位(载荷轮换 + 插桩就绪 + 批内相关实测)
- min 兜底使 bootstrap 分支只能收紧不能放松——牺牲了"检出真实负相关下更优表现"的可能
  (审慎权衡:R2 语境宁可漏晋级不可误晋级)
