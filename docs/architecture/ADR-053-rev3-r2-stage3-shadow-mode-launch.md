## 决策 3A′-P:胜率门参数(闭合 R2-E06-1/2/4)

### 判定规则(预注册,唯一,删除 rev2 的"0.714 仍适用"回退)

消除 rev2 "独立→0.714 / 自相关→bootstrap" 的双规则歧义(rule-shopping 风险),
改为**预注册的确定性二分**:

1. **独立性哨兵**:对批次胜负序列跑 **Wald–Wolfowitz 游程检验,α=0.10**(故意取宽,
   使"疑似相关"更易触发保守分支,方向对 R2 不利 = fail-closed)。
2. **哨兵不拒绝(判独立)→ 唯一判定 = Wilson 单侧 95% 下界 > 0.5**。依据:独立二值
   序列上 block bootstrap(L=1)渐近等价于二项模型,解析 Wilson 优于重采样(无 MC
   噪声、小样本覆盖率有 Brown-Cai-DasGupta 2001 背书)。
3. **哨兵拒绝(疑相关)→ moving block bootstrap,块长 L=3,B=10000,percentile 单侧
   95% 下界 > 0.5**。**排除 BCa**(二值小样本 jackknife 伪值退化,加速常数不稳)。

### 样本量 + R1 算术订正(闭合 R2-E06-4)

精确二项概率(n=14,p=0.5,分母 2¹⁴=16384):

| 事件 | 精确值 | 是否 <0.05 |
|------|--------|-----------|
| P(X≥10) | 1471/16384 = **0.0898** | ❌(R1 注释误称 5.9%) |
| P(X≥11) | 470/16384 = **0.0287** | ✅ |
| P(X≥12) | 106/16384 = 0.0065 | ✅ |

- **晋级临界胜数 = ≥11/14**(胜率 ≈0.786);Wilson 单侧 95% 下界交叉验证:11/14 → 0.568>0.5 ✓;10/14 → 0.494<0.5 ✗,两法在 n=14 同临界,规则自洽。
- **须订正**:R1 `omega-learner/shadow_mode.rs` 与 `gsoe-evolution/significance.rs` **两处**
  注释均复述了错误的 5.9%(实为 8.98%),订正为"≥11/14 才达 p<0.05"。因主判定已换
  Wilson/bootstrap,不阻断,列阶段③ 启动前订正项。
- **检出力**:14 批仅对强优势(真实批胜率 ≳0.84)有 ≥80% 检出力(p=0.75 时 power≈0.52)。
  **预注册扩展规则**:若 14 批后 Wilson 下界落 [0.45, 0.5](接近未过),**扩展至预注册的
  25 批**再做唯一终判;**禁止中途窥视后随意加批**(防 optional stopping 的 α 膨胀)。
  > ⚠️ **n=25 临界修正(复评 H1)**:以 **Wilson 单侧 95% 下界>0.5 为唯一主判定**,
  > n=25 临界 = **≥17/25**(17/25 下界 0.5156>0.5)。**披露分歧**:精确二项在 n=25 处
  > 临界为 **≥18/25**(P(X≥17|25)=0.0539>0.05,P(X≥18)=0.0216<0.05)——Wilson 与二项
  > 在 n=25 不同临界(n=14 时同为 11)。主判定统一以 Wilson 为准,二项仅作诊断参考。

### 快照单元定义(闭合 R2-E06-2,消解进化连续性张力)

> **每批开评时对 R2 进化谱系取一个只读不可变快照(内容寻址,类 git commit),整批
> 只对该快照评估;谱系进化在批间照常连续推进,但本批评估结果与本批任务集永不回流
> 为任何进化反馈信号,且每批任务集为全新抽样、未在既往进化/评估中出现。**

独立性要求的不是"停止进化",而是"评估单元间无信息流":快照切断"评估对象随批漂移",
任务新抽样 + 结果不回流切断"评估→进化→下批"反馈耦合。谱系连续性完好。

## 决策 3A″-P:外部门参数(闭合 R2-E02-1/2/3/4)

### 去重正交维度 + 权重下界(闭合 R2-E02-1)

rev2 五维实为"~3.5 维"(①pass_rate 与 ②真实执行同次沙箱执行、共线)。**去重为
4 正交维**,其中 3 维进加权复合得分、1 维作合取硬门:

| 维 | 度量 | 角色 | 权重下界 |
|----|------|------|---------|
| A 执行面 | pass_rate(①②合并,真实执行为硬门前提) | 加权 | w_min ≥ **0.20** |
| B 变异分 | mutation score | 加权 | w_min ≥ **0.20** |
| C held-out | held-out 对抗集得分 | 加权 | w_min ≥ **0.20** |
| D AHIRT | 红队新增发现 | **合取硬门**(不进加权) | — |

- **w_min=0.20 推导**:3 加权维均分 1/3,取"均分下限的一半"1/(2×3)≈0.167,宁严向上
  取 **0.20**。推论:权重和=1 约束下单维上限 = 1−2×0.20 = **0.60**,复合门**不可能退化
  为单维**(单维最多贡献六成),且每维至少保留均分的六成,不沦为装饰。
- **复合得分归一化区间 = [0,1]**(三维凸组合,各维域[0,1]、权重和1);配对差值域 [−1,+1]。

### 合取硬门 vs 加权分(资格 vs 排名)

- **合取硬门**(任一失败该批直接计非胜,与权重无关,fail-closed):① 真实执行检查为真
  (耗时>10ms ∧ **独立插桩**覆盖率>0);② D 维 AHIRT 门(见下);③ 覆盖率一致性门
  (独立插桩 vs 自报差 ≤ 容差);④ 批内样本量充足(3A′ 规则)。
- **加权复合得分**(供 3A′ 配对差值判定):仅 A/B/C 三维,权重各 ≥0.20、和为 1。
  硬门是"资格",加权分是"排名"——资格不过不看排名,排名博弈不影响资格。

### AHIRT 门 N_probe(闭合 R2-E02-2)

- **N_probe = 100 且每攻击类别 ≥ 25**(依据:AHIRT 内置载荷库 4 类各 25 共 100;
  "三法则"下 100 次零发现的真实漏洞率 95% 上界 ≈3%,与 AHIRT 既有 0.95 阈值同量级;
  per-category≥25 防"堆单类凑总量"的类别偏斜)。
- **fail-closed 规则**:批窗内 total_probes<100 / 任一类别<25 / failed_probes>0 / 未收到本批
  AHIRT 完成事件(缺失视同零探测)→ 一律计非胜、不剔除、分母不动。**门禁语义须 L9
  编排器新接线消费**(gsoe 现有处理器语义是"提升变异率",不得复用为门禁)。

### held-out 构造规格(闭合 R2-E02-3)

独立来源构造(R2 管线外,人工或零共享语料的冻结生成器)+ 对 R2 谱系保密(仅公布
哈希承诺清单,评估后可验证未篡改)+ 每批 ≥30 任务 + **池规模 ≥420(复评 H2 订正:
14 批 × 每批 30 且窗内不复用 = 420,原"≥90"为算术错误)** + 每晋级窗全量轮换、窗内
不复用;疑泄漏即整池作废 + 当窗批次全计非胜。若扩展至 25 批,池规模同步升至 ≥750。

### coverage 独立插桩(闭合 R2-E02-4)

- 覆盖率须由 L9 编排器在 seccore 沙箱内以**进程外独立插桩**(cargo-llvm-cov 优先 /
  tarpaulin 备选)采集,插桩配置/产物路径对变体不可写,门禁只读独立值。
- 自报 coverage 保留仅作交叉校验:独立值 vs 自报值差 >容差 → 该批 fail-closed 计非胜。
- **降级方案**(独立插桩未就绪):coverage 禁止参与任何计权/门槛,①② 严格按单一执行面
  计权 + 每批人工抽样 ≥3 变体执行证据;**降级态不得进入晋级判定窗,仅允许预热观察**。

## 决策 3C-P:ε_win(闭合 R2-E06-3,依赖顺序显式)

- **依赖顺序(硬约束)**:E02 权重公式 → 复合得分量纲([0,1]已定)→ ε_win 数值。
  **ε_win 不得先于权重定死**。
- **条件公式**:复合得分归一化 [0,1] 下,**ε_win = max(0.02, 2·σ̂_d/√m)**——0.02 继承 R1
  平局带先例(约满分 2%),2·σ̂_d/√m 覆盖批均值差约 95% 纯噪声波动(把"噪声胜"划入
  平局按 fail-closed 计非胜)。**σ̂_d(批内配对差值标准差)、m(批内任务数)只能实跑标定**。

## 后果

**正面**:
- P0 参数从"框架"落到"带推导依据的具体值",消除 rule-shopping(唯一判定规则)、
  单维退化(w_min=0.20 → 单维上限 0.60)、恒真门(N_probe=100 + fail-closed)
- 诚实分离"可定死"与"须实跑",不把待标定值伪装成既定值——延续 rev2 的接地诚实
- 订正了追溯到 R1 的 5.9% 算术错误(两处注释)

**负面/风险**:
- 独立插桩(cargo-llvm-cov)+ 变异测试(cargo-mutants)+ held-out 池 + N_probe=100 全库扫描,
  阶段③ 启动工程量与算力开销显著
- 14 批仅对强优势有足够检出力,中等优势须扩至 25 批,晋级更慢(审慎权衡)
- ε_win / 权重 / 基线仍须实跑标定,rev3 只定框架与下界,非终值
