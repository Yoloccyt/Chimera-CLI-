## 决策 2:影子模式作用域隔离(E02-3.1 修复,前置于阈值)

**核心澄清**:阶段③ 影子模式下,`UnfreezeGovernor::decide()` 返回 `Allowed`
**不代表 RL 输出写入生产进化谱系**,而是:

| 路径 | 作用域 | 权威性 |
|------|--------|--------|
| **生产路径**:`GsoeEvolutionEngine::evolve_once`(L3 执行反馈) | 生产进化谱系 | **唯一权威**,阶段③ 不变 |
| **R2 影子路径**:decide()==Allowed 的 R2 输出 | **影子副本**(隔离存储) | **仅记录 + 与生产对比**,永不写生产谱系 |

这忠实落地 ADR-042 决策 3 阶段 3"R2 训练策略不部署到生产路径(仅记录与对比)"。
影子副本与生产谱系物理隔离,R2 被奖励黑客污染也无法影响生产代码质量——**这是
比 rev0 更根本的安全边界**(rev0 的 Allowed 语义模糊,可能被误读为写生产)。

## 决策 3:双门阈值体系(E06 C-1/C-2/C-3/C-4 修复)

> 设计原则:**正面门抗奖励黑客(晋级必要),负面门统计可行(中止合理)**。

### 3A. 正面外部证据门(晋级必要条件,抗奖励黑客)★核心修复

**问题根源(E06 C-3)**:伪 regret 依赖 R2 内部奖励模型,被奖励黑客的策略
**定义上就在最大化该奖励**,故 regret 必然漂亮非增——内部信号对奖励黑客盲区。

**解决**:恢复 R1 的**外部对比证据**(ADR-043 `shadow_mode.rs` 先例),用**独立于
R2 内部奖励**的信号判定晋级:

| 门 | 阈值 | 统计依据 | 抗黑客原理 |
|----|------|---------|-----------|
| R2 vs L3 执行反馈胜率 | **≥ 0.714**(14 天 ≥10 天胜) | 单尾二项检验 p<0.05(复用 R1 `DEFAULT_WIN_RATE_THRESHOLD`) | L3 执行反馈(测试通过率/真实质量)独立于 R2 内部奖励;被黑客的策略骗不过真实执行 |
| 每日最小对比样本 | **N_min ≥ 30**/日 | 保证日胜负判定的统计功效 | 低样本日方差过大,不计入胜率 |

**晋级必须同时满足**:外部胜率 ≥0.714 **且** 负面异常门全程未触发。仅"没出事"
(rev0 的唯一晋级条件)**不充分**——必须有独立于内部奖励的**正面**证据。

### 3B. 负面异常门(中止条件,统计可行 + 信号分级)

**信号分级(E06 C-1 修复)**——确定性信号即时熔断,统计性信号加确认窗:

| 信号类型 | 指标 | 阈值 | 触发动作 |
|---------|------|------|---------|
| **确定性**(0 容忍) | 范围越界(governor OutOfScope) | 1 次 | 即时永久跳闸 + 重冻结 |
| **确定性**(0 容忍) | CI 门禁 FormalPropertyViolated | 1 次 | 阻断提交 + 跳闸 |
| **确定性**(0 容忍) | UNLEARNABLE 红线触碰 | 1 次 | 即时永久跳闸 + Critical 告警 |
| **统计性**(确认窗) | 执行反馈显著退化 | **连续 3 天** z 检验 p<0.01(非 rev0 的 1 天) | 暂停 + 人工 24h 复核,非自动永久跳闸 |
| **统计性**(确认窗) | 成功率 EWMA 崩塌 | 24h 内跌 ≥0.3(R1 先例,正确接地) | 暂停 + 人工复核 |

**收敛判据(E06 C-2/C-4 修复)**——替换 rev0 的微观 2 步块 0 容忍:

- **日级聚合**:regret 按自然日聚合(非逐步 128 窗口),消除探索步微观抖动
- **趋势检验**:用累计 regret 对 √T 的回归斜率 或 日均 regret 的 Mann-Kendall 趋势
  检验(带置信区间),判定长程收敛——**不要求逐步/短窗单调**(LinUCB 探索步产生
  瞬时 regret 尖峰是算法正确特征,与 O(√T) 上界不矛盾)
- **预热豁免**:阶段③ 每子阶段**前 2 天仅采集不判罚**,保护冷启动探索期
- **regret 门定位澄清**:regret 趋势是 R2 新造的**辅助**收敛观测(非晋级充分条件),
  晋级充分性由 3A 外部证据门承载;regret 仅在**日级发散**(Mann-Kendall 显著上升)
  时作为统计性异常信号进入确认窗

### 3C. assess_trend 四元组(E06 条件项,可操作化)

| 参数 | rev1 取值 | 说明 |
|------|----------|------|
| 每日最小样本 | ≥30 步 | 低于则该日趋势不判定 |
| 聚合窗口 | **日级**(非 2 步块) | 每日一个聚合点,窗口为"日" |
| 容差 | 按观测方差标定(非固定 0.05) | 日聚合方差的 2σ |
| 评估频率 | 每日 1 次(非每步) | 与日级聚合一致 |

## 决策 4:中止协议编排器归属(E01 A-B1 修复)

**编排器落点**:`ShadowModeOrchestrator @ L9`(Quest 层,建议 chimera-mas 或专用
L9 协调 crate)。依赖方向(全部向下,§2.2 合规,无环):

```
ShadowModeOrchestrator (L9)
  ├─→ omega-learner (L6):读 RegretCollector 后悔率趋势
  ├─→ gsoe-evolution (L5):UnfreezeGovernor.decide + UnfreezeScope.revoke_all
  ├─→ decay-engine   (L4):ShadowModeCircuitBreaker.observe / reset(授权)
  └─→ event-bus      (L1):发布 R2FreezeViolation Critical(走 mpsc 旁路)
```

**为何 L9**:中止协议三动作分属 L4/L5/L1,decay-engine(L4)不依赖 event-bus 故
熔断器**自身无法发告警**(rev0 硬伤);唯有 L7+ 层可同时向下依赖这些 crate。
chimera-mas(L9)已依赖 event-bus + gsoe-evolution,增补 decay-engine + omega-learner
(均向下)即可承载。**编排器实现与接线是阶段③ 启动后动作,不在 R2 冻结期实施**。

中止协议(编排器执行):① 熔断器 observe 得 Violated → 永久跳闸;②
`UnfreezeScope::revoke_all()` 原子重冻结(S-2.2 已就位);③ 发布 R2FreezeViolation;
④ 熔断器 reset 须 `ResetAuthorization`(S-2.1 已就位,E01+E02 联签)。

## 决策 5:验证器游戏化元风险防御(E02-3.2 修复)

| 防线 | 机制 |
|------|------|
| **主防线** | 决策 3A 外部证据门——被黑客策略骗不过独立 L3 执行反馈,从根上抗游戏化 |
| 人工抽样审计 | 观察期内每周人工抽查 N 个 R2 变体(独立于自动验证器) |
| 属性集冻结 | 7 验证器属性 + UNLEARNABLE 为编译期常量(`seccore` 已固化),不可被 config 游戏化 |
| 潜伏防御 | 观察期最后 48h 加大验证采样密度 + 前后 7 天分布比较(防"13 天正常 + 第 14 天爆发") |

## 决策 6:晋级门(进入 ADR-054,不预批)

③-a + ③-b 各满 ≥14 天,**且同时满足**:(a) 外部胜率 ≥0.714;(b) 负面异常门全程
未触发确定性信号、统计性信号经复核未确认退化;方可另立 **ADR-054** 三方复核解冻。
**本 ADR 不含晋级批准**。

## 后果

**正面**:
- 晋级判据从"没出事"升级为"有独立于内部奖励的正面证据 + 统计可行的异常门",
  直接堵住 E06 指出的奖励黑客盲区
- 信号分级(确定性 0 容忍 / 统计性确认窗)使观察实验统计可行,消除 76% 误中止
- 影子副本隔离 + 编排器层归属明确,消除 rev0 的作用域歧义与架构悬空

**负面/风险**:
- 引入外部对比需 R2 影子副本 + L3 生产双跑基础设施(阶段③ 启动工程量增加)
- 外部胜率门 + 长观察期使晋级更慢——审慎权衡,R2 奖励黑客风险高于晋级速度
- Mann-Kendall / z 检验的日级样本需求对低流量环境是约束(N_min≥30/日)
