# R12 · 接口契约与类型草案

- 批次：R12
- 目的：把 R12 的新增能力写成**可直接落码**的接口，并逐条判定"是否破坏既有契约"
- 约束：edition 2021 / MSRV 1.97 / `#![forbid(unsafe_code)]` / 不新增 crate / L0 类型零外部业务依赖
- 证据：现状签名均取自基线提交实读，行号见各处

---

## 1. 兼容性判据：先定义"什么叫没破坏"

用户要求「100% 保证所有现有工具能力不削减、接口契约完全兼容、功能无退化」。这句话必须能被机器判定，否则只是口号。本文采用四条可核对判据：

| # | 判据 | 判定方式 |
|---|---|---|
| C1 | **L0 已有类型的字段集合与变体集合不变** | `git diff` 中 `nexus-contracts*/src/spec/*.rs` 删除行数为 0 |
| C2 | **公开函数签名不变**（可新增，不可改签名/删） | `cargo public-api` 或逐文件 `git diff` 审阅；R12 只用"新增" |
| C3 | **默认行为逐位不变**（未开新开关时） | 既有测试全绿 + 专项等价性测试（见 `08` 文） |
| C4 | **serde 线形态向后兼容**（新字段有 `#[serde(default)]`） | 反序列化旧 payload 的往返测试 |

**已确认的例外（必须登记，不能假装不存在）**：

- 给 `ContextItem` 加字段会打破 **4 处**结构体字面量（全在 `crates/hcw-window`，实测 4 处）⇒ 属**仓内源码改动**，非外部契约破坏。workspace 内 crate 互为唯一消费者，但 R12 必须在提交信息里显式写明这 4 处的同步修改。
- 给 `ToolNode`（34 处字面量：gqep 24 / chimera-cli 4 / nexus-contracts 6）**一律不改** —— 改动面太大，且我们的设计不需要它。

## 2. L0 新增：资源访问集（新文件，不改既有类型）

**文件**：`crates/nexus-contracts/src/spec/tool_access.rs`（新增）
**导出**：`crates/nexus-contracts/src/spec/mod.rs` 追加 `pub mod tool_access; pub use tool_access::{AccessSet, ResourceRef, ToolClass};`
**依赖**：仅 `serde`（L0 铁律）

```rust
//! 资源访问集 — 工具调用之间的冲突判定原语（R12）
//!
//! WHY 独立于 `SideEffectDecl`：后者是二元的「只读/写」且无 `#[non_exhaustive]`
//! （`spec/tool_plan.rs:59-66`），加变体会让所有下游 match 变成非穷尽 = 编译期破坏。
//! 本模块以**独立可选结构**承载更细的粒度，既有路径零感知。

use serde::{Deserialize, Serialize};

/// 资源引用 — 冲突判定的最小单位
///
/// 语义：`Path` 的前缀关系视作冲突（`a/b` 与 `a/b/c` 冲突）；
/// 其余按**精确相等**判定（保守：宁可多串行，不可漏串行）。
#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(rename_all = "snake_case", tag = "kind", content = "value")]
pub enum ResourceRef {
    /// 文件系统路径（相对工作区根）
    Path(String),
    /// 网络端点（`host:port` 或 provider id）
    Endpoint(String),
    /// 环境变量名
    Env(String),
    /// 子进程族（可执行文件名）
    Process(String),
    /// 宿主全局互斥（终端/剪贴板/全局配置）
    Exclusive(String),
    /// 未知 — 与一切冲突
    Unknown,
}

/// 一次工具调用的读写集
#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct AccessSet {
    /// 读集（空 = 不读任何外部资源）
    #[serde(default)]
    pub reads: Vec<ResourceRef>,
    /// 写集（空 = 无副作用）
    #[serde(default)]
    pub writes: Vec<ResourceRef>,
}

/// 资源类别 — 决定许可权重（见 `06 §5` 与 `05 §8`）
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ToolClass {
    /// 纯本地计算
    Cpu,
    /// 文件/DB I/O
    Io,
    /// 远端调用
    Net,
    /// 宿主全局互斥
    Exclusive,
}

impl AccessSet {
    /// 是否含未知资源（含则与一切冲突）
    #[must_use]
    pub fn has_unknown(&self) -> bool {
        self.reads.iter().chain(self.writes.iter()).any(|r| matches!(r, ResourceRef::Unknown))
    }

    /// 由读写集推导资源类别（无额外声明方法，避免再加一条装饰器穿透链）
    ///
    /// 优先级：Exclusive > Process(Cpu) > Endpoint(Net) > Path(Io) > Cpu
    #[must_use]
    pub fn class(&self) -> ToolClass {
        if self.writes.iter().any(|r| matches!(r, ResourceRef::Exclusive(_))) {
            return ToolClass::Exclusive;
        }
        if self.writes.iter().any(|r| matches!(r, ResourceRef::Process(_))) {
            return ToolClass::Cpu;
        }
        if self.reads.iter().chain(self.writes.iter()).any(|r| matches!(r, ResourceRef::Endpoint(_))) {
            return ToolClass::Net;
        }
        if self.reads.iter().chain(self.writes.iter()).any(|r| matches!(r, ResourceRef::Path(_))) {
            return ToolClass::Io;
        }
        ToolClass::Cpu
    }
}

/// 两个访问集是否冲突 —— 冲突 ⇒ 不可并发（保守方向）
///
/// 性质（`tests/tool_access_proptest.rs` 锁定）：
/// 对称、单调（加元素不会由冲突变不冲突）、空集与纯读集互不冲突。
#[must_use]
pub fn conflicts(a: &AccessSet, b: &AccessSet) -> bool {
    if a.has_unknown() || b.has_unknown() {
        return true;
    }
    let path_overlap = |x: &ResourceRef, y: &ResourceRef| match (x, y) {
        (ResourceRef::Path(p), ResourceRef::Path(q)) => p == q || p.starts_with(&format!("{q}/")) || q.starts_with(&format!("{p}/")),
        _ => x == y,
    };
    a.writes.iter().any(|w| b.writes.iter().any(|o| path_overlap(w, o)))
        || a.writes.iter().any(|w| b.reads.iter().any(|o| path_overlap(w, o)))
        || b.writes.iter().any(|w| a.reads.iter().any(|o| path_overlap(w, o)))
}
```

**为什么不放在 `tool_plan.rs` 里**：`tool_plan.rs` 是 WI-16 计划 DSL 的契约文件，已有 366 行且被 34 处字面量引用；新概念独立成文件，`git blame` 与回滚边界都更干净。

### 3.1 查询链（在既有三级之后追加，不插队）

```rust
/// 节点访问集的有效来源 — 与 `effective_side_effect` 同一优先级哲学
///
/// 1. 执行器批量访问集表（`declared_access`）

pub(crate) fn effective_access(
    executor: &dyn ToolExecutor,
    tool: &str,
) -> Option<nexus_contracts::tool_access::AccessSet> {
    executor
        .declared_access()
        .into_iter()
        .find(|(name, _)| name == tool)
        .map(|(_, a)| a)
}
```

/// 计划调度策略 — 三档，默认与既有行为逐位等价
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]

## 5. L7 新增：资源治理器（跨执行面共享预算）

**问题**：现状 6 个执行面各自 8（`05 §4`），叠加后对下游是过订阅；且 MCP 无 per-server 限流。

```rust
/// 资源治理器 — 跨执行面共享的许可中枢
///
/// WHY trait 而非全局静态：全局静态会让并行测试互相污染（criterion 与
/// `#[tokio::test]` 同进程跑），也违反"组合根唯一装配"纪律。
/// 实例由组合根构造并注入，未注入处行为逐字不变。
#[async_trait::async_trait]
pub trait ResourceGovernor: Send + Sync {
    /// 按资源类别取许可；持有到工具执行结束（RAII 归还）
    async fn acquire(&self, class: ToolClass) -> Result<GovPermit, GovError>;
    /// 当前占用快照（诊断/测试断言）
    fn snapshot(&self) -> GovSnapshot;
}

/// 许可集合 — drop 即归还（无显式 release API，杜绝漏还）
#[derive(Debug)]
pub struct GovPermit { /* 持有各类别的 OwnedSemaphorePermit */ }

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct GovSnapshot {
    pub cpu_in_flight: usize,
    pub io_in_flight: usize,
    pub net_in_flight: usize,
    pub exclusive_in_flight: usize,
    pub waiters: usize,
    pub peak_in_flight: usize,
    /// 过订阅率（千分比）：inflight / effective_limit，>1000 即过订阅
    pub oversubscription_bp: u32,
}

#[derive(Debug, thiserror::Error)]
pub enum GovError {
    #[error("governor cancelled")]
    Cancelled,
    #[error("governor saturated: waiters={waiters}")]
    Saturated { waiters: usize },
}
```

**默认实现（不启用时也装配，但 `off` 档直接放行）**：

```rust
pub struct StaticGovernor {
    cpu: Arc<Semaphore>, io: Arc<Semaphore>, net: Arc<Semaphore>, excl: Arc<Semaphore>,
    // …
}
impl StaticGovernor {
    /// `mode = Off` ⇒ 四类信号量权值取 `Semaphore::MAX_PERMITS` 的钳制值，
    /// 等于放行；`Observe` ⇒ 记录 snapshot 但许可等同 Off；`Apply` ⇒ 真限流
    pub fn new(mode: GovMode, limits: GovLimits) -> Self { /* ... */ }
}
```

**`GovMode` 三态**沿用 ADR-198 的 `off/observe/apply` 先例（`HCW` 校准闭环同款），默认 `Off`。

## 6. L7 新增：调度遥测

```rust
/// 单次调度快照（有限取值域，无高基数标签 —— 对齐 `BatchAttribution` 的指标纪律）
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct ScheduleSnapshot {
    pub policy: SchedulePolicy,
    pub nodes_total: usize,
    pub nodes_executed: usize,
    /// 就绪队列峰值深度
    pub ready_queue_peak: usize,
    /// 在飞峰值
    pub inflight_peak: usize,
    /// 排队等待总时长（ms）与 p95
    pub wait_ms_total: u64,
    pub wait_ms_p95: u64,
    /// makespan（ms）与理论下界（Σ service / width）
    pub makespan_ms: u64,
    pub critical_path_ms: u64,
    /// 并行效率（千分比）：Σservice / (makespan × width)
    pub efficiency_bp: u32,
}

/// 遥测出口 — 与 `BatchAttributionSink`（`tool_runtime/batch.rs:170-173`）同构
pub trait ScheduleSink: Send + Sync {
    fn record(&self, snap: &ScheduleSnapshot);
}
```

**指标纪律**：只放有限取值域的计数与比率；**不放**工具名、参数、路径（高基数会把时序库打爆 —— 该教训已写在 `batch.rs:109-119`）。

## 8. 退化与失败姿态（与既有纪律对齐）

| 场景 | 行为 | 依据 |
|---|---|---|
| `AccessSet` 未声明 | 视为 `Unknown` ⇒ 冲突 ⇒ 串行 | 与 `node_is_read_safe` 的「未知按可能写」同口径（`toolplan_runner.rs:561-568`） |
| `ResourceGovernor` 未注入 | 各处沿用静态上界，行为不变 | 组合根唯一装配纪律 |
| 治理器饱和（`waiters` 超限） | 返回 `GovError::Saturated`，**不排队**（fail-fast） | 与未合并分支 `BoundedToolScheduler` 的 `max_waiters` 同思路 |
| 遥测出口未注入 | 零开销（不构造 snapshot） | 与 `batch.rs` 的 `sink: Option<&dyn _>` 同构 |
| 调度策略非法值（配置） | 回退 `Layered` + 一次 warn | 表驱动解析先例：`resolve_action_concurrency`（`action_orchestrator.rs:361-388`） |

## 9. 明确不做的接口（减法）

| 不做 | 理由 |
|---|---|
| 给 `SideEffectDecl` 加第三变体 | 无 `#[non_exhaustive]`，加变体 = 编译期破坏 |
| 给 `ToolNode` 加字段 | 34 处字面量，改动面与收益不成比例 |
| 新建 `tool-scheduler` crate | 48 crate 预算 + 可达性棘轮登记负担；L7 内新增模块足够 |
| 引入 `dynosaur`/`async fn in trait` 替换 `#[async_trait]` | `Box<dyn ToolExecutor>` 在场，AFIT 非 dyn-compatible；本项无收益 |
| 在治理器里做优先级抢占 | 需要重写 FuturesUnordered 语义；R12 只做"准入"，不做"抢占" |
| 把 `StreamingDispatcher` 硬接生产 | 前置 mca `stream()` 未实装（`crates/mca-gateway/src/adapters.rs:10` 自述属 M1 交付） |
