# ADR-290：跨会话记忆一致性契约与只读审计

- **状态**：Accepted
- **日期**：2026-11-12
- **批次**：R9 / W3-T1
- **相关**：ADR-141（session-store）、ADR-109（k-way 回放）、ADR-201（model-visible 投影）、ADR-259 D3（读面维持预留）、ADR-288/289（R8 记忆热路径）

## 背景

跨会话记忆由多个存储面共同承载：

| 存储面 | 权威数据 | 现状 |
|--------|---------|------|
| `session-store` 段文件 | append-only JSONL（`[u32 LE 长度][JSON][\n]`） | 写面 PRODUCTION-WIRED；读面 `replay_since` 按 ADR-259 D3 维持预留（仅测试可达） |
| `session-store` 树索引 | SQLite `segments` / `events` | 与段文件同目录 `index.db`；崩溃恢复以段文件为权威源 |
| `cmt-tiering` 经验卡 | SQLite `experience_cards`（`card_id` 主键） | 生产闭环接线；`ON CONFLICT(card_id) DO UPDATE` 幂等 |
| `mlc-engine` L2/L3 | 内存层 + SQLite 程序性记忆 | R8 已完成热路径削减 |

缺口：**没有跨存储的一致性判据**。段/索引不一致、经验卡重复、seq 非单调等问题只能靠人工发现；「读面预留」的装配态也容易被后续读者误读为生产可用。

## 决策

### D1 单写者假设（多实例非目标）

同一 `~/.chimera` 数据目录在同一时刻只允许一个进程写入。多进程/多实例并发写同一目录**不是目标**，不引入跨进程锁或分布式事务。

理由：当前生产装配是单进程 CLI/宿主；引入分布式一致性属于过度工程，且会把故障面从「本地 IO」扩大到「协调服务」。

### D2 段文件为权威源，索引为加速面

- 崩溃恢复与回放以段文件为准（ADR-109 既有口径）；
- 树索引只用于读加速，索引缺失/陈旧不影响回放正确性；
- 审计器把「索引孤儿行」与「缺索引行」列为发现，但不自动修复（只读）。

### D3 经验卡幂等键 = `card_id`

`experience_cards.card_id` 为主键，写入使用 `ON CONFLICT(card_id) DO UPDATE`（既有实现）。同一卡片重复投递 K 次只保留一行；重复投递的去重计数由存储层指标记录。

### D4 读面维持预留（不重开 ADR-259 D3）

`AppServer::replay_since` 维持「仅测试可达」。本轮**不**把读面接入生产恢复路径，也**不**新增 CLI 命令。装配态用测试锁定：

- 生产段（`#[cfg(test)]` 之前）不得出现 `.replay_since(` 调用；
- `chimera-cli/src/composition.rs` 不得出现 `replay_since`。

理由：ADR-259 D3 已裁决；在没有断线重连协议面的情况下强行接线等于虚构消费。

### D5 只读一致性审计器

新增 `scripts/audit_memory_consistency.py`：

- 检查：截断尾部 / 非法 JSON / row 断档 / seq 非单调 / 段索引缺口 / 索引孤儿与缺失 / 经验卡重复；
- `--self-test` 用临时样本验证牙口（坏例 3/3 必抓、正常样本零误报）；
- 退出码：0 无发现、1 有发现、2 输入/IO 错误；
- 只读：不创建、不修改、不删除任何业务文件。

审计器当前为**手动/诊断面**，尚未接入 CI 阻塞门；是否门化需独立裁决（会改变 CI 阻塞面）。

### D6 一致性不变量（机器可判）

| 不变量 | 判据 |
|--------|------|
| I-1 行连续 | 段内 `row` 从 0 起逐条 +1 |
| I-2 序列单调 | 同一会话跨段 `seq` 严格递增且无重复 |
| I-3 段索引连续 | 会话段索引从首段起无缺口 |
| I-4 长度前缀自洽 | 每条记录的实际字节数等于 `u32 LE` 前缀声明值 |
| I-5 索引引用完整 | `segments` 每行有对应段文件；每个段文件有索引行（索引库存在时） |
| I-6 卡片唯一 | `experience_cards.card_id` 无重复 |

## 后果

- **正面**：跨存储不一致从「人工发现」变为「可执行判据」；读面装配态有反向锁；经验卡幂等有自动化验证。
- **负面/边界**：单写者假设意味着多实例场景不受支持且无运行时保护（仅文档与审计）；审计器未入门禁，漂移仍可能晚发现。
- **不做**：跨进程事务、自动修复、把读面接生产（均需独立 ADR）。

## 回滚

本 ADR 仅引入只读脚本、测试与文档，无生产代码变更。回滚 = 删除 `scripts/audit_memory_consistency.py`、对应测试与本文档，并移除 `adr_index.md` 登记行；无数据迁移。
